# Student Record Manager

A command-line student management application built with Python.

This project allows users to manage student records through a simple menu-driven interface. Student information is stored locally using JSON, so records remain available after restarting the application.

## Features

- Add new students
- View all student records
- Search for a student by name
- Update student scores
- Delete student records
- Save and load records using JSON

## Technologies Used

- Python
- JSON

## How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run:

```bash
python main.py
```
